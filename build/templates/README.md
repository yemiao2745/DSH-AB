# DSH-AB

DSH-AB 是一套 DSH 安装的入口、切槽与托盘宿主：`DSH_AB.exe` 只启动/停止 dsh 与探测端口，自己不往槽里写东西
（安装器只往 `slot-a\data\skills\` 放随包那份 skill）。

## 文件结构

```
<安装根>\
  DSH_AB.exe    入口程序：托盘宿主 + 启动器（GUI 子系统，双击无控制台）
  dsh-ab.toml   配置。归用户管；改完要重启 DSH_AB.exe 才生效
  README.md     本文件（随包安装）
  LICENSES.txt  第三方许可证（随包安装）
  .gitignore    快照仓库的忽略规则（随包安装）
  docs\
    PLUGINS.md  插件与改动台账。AI 维护
    TODO.md     本轮待办。AI 维护
  slot-a\       随包安装的完整实例，默认的活动槽
  slot-b\       装好时是空目录。改 dsh 前由 AI 把活动槽整份复制进来
  runtime\git\  内置便携版 Git。AI 打快照用
  state\        活动槽指针与待生效的切槽登记。DSH-AB 写
  logs\         日志目录。DSH-AB 写；级别 off 只记 error，auto 再加 warn/debug，full 全记（含子进程输出）
```

## 槽位

同一时刻只有一个槽是**活动槽**：它对外服务生产端口，并持有正在使用的数据；安装后 slot-b 是**空目录**。登记一次切换只写
state\pending.json，两个槽与 dsh 进程都保持运行；**只有点托盘的「重启」才会切槽**——关掉再打开不会切换，登记保留、也可撤销。

## 托盘菜单（六项固定，左键与右键同一个菜单）

| 序 | 菜单项 | 行为 |
| - | ---- | ---- |
| 1 | 打开浏览器 | 先预检端口与进程，两者都正常才打开 |
| 2 | 当前状态 | 活动槽、端口、两个槽的状态、切换登记、日志级别、配置状态、安装根、版本、日志路径 |
| 3 | log：off / auto / full | 单击循环三档（off 只记 error；auto 再加 warn/debug；full 全记，含 dsh 子进程输出）；改档只在托盘与日志里可见，界面保持安静；只对本次运行有效 |
| 4 | 槽位切换 / 槽位切换：待生效 | 登记或撤销切换：只写登记，两个槽与 dsh 进程保持运行 |
| 5 | 重启 | 停掉 dsh，再启动本次该跑的槽（先确认） |
| 6 | 退出 | 停掉 dsh 并退出托盘（先确认） |

## 需要知道的行为

- **名字**：由本机上的份数决定（唯一时 `DSH-AB`，共存时带生产端口，端口用不了时改带 tag），细节在托盘「当前状态」里；
  快捷方式永远直接放在 `开始菜单\程序\` 下、没有子文件夹，名字不看安装目录名。**托盘提示只有状态 + 生产端口**
  （不带安装名）：`DSH 运行中（端口 <生产端口>）` / `DSH 未运行（端口 <生产端口>）`。
- 发现故障时只提示你（同类故障在一个节流窗口内不重复提示，见 `health.popup_throttle_min`）；**需要重启时由你在托盘点
  「重启」**。启动失败的弹窗给出子进程最后的输出、日志路径、安装根与下一步，端口被占会直接说明并指向 `ports.production`。
- 安装程序只接受空文件夹，并要求填写的生产端口没被占用；它**不阻止**你再装一份。向导里默认端口被占用时端口页会预填第一个空闲
  端口；**静默安装不换端口**，占用就报错中止。**没有覆盖升级**：升级 = 装到新的空文件夹。
- 卸载先提醒你在托盘「退出」，再问用户数据（默认保留，位置 `<安装根>\slot-*\data`）；删不掉的项会逐条列出。
- **dsh 的自我升级**是把新版 dsh 覆盖进**非活动槽**，在一个空闲端口上验证后登记切槽、由你点「重启」；就地更新这一份安装，
  另建目录那份是另一套安装、两者数据各管各的。细节在随包 skill 里。
- **就地更新 DSH-AB 自己**：Release 里除安装包外还有一份 `DSH-AB-<版本>-update.zip`——覆盖到安装根上就是更新：dsh 与托盘
  都不用重启，`dsh-ab.toml`、`state\` 与 `docs\` 里的台账原样保留（包不带台账）；**回退靠安装根更新前的 git 快照**。
  流程写在随包 skill 里，不随包发脚本。
